Validation & analysis

Tests cover N=0, N=1, N=2, duplicates, all-identical points, collinear points, equal x/y coordinates, tied minima, a cross-split pair, negative coordinates, and floating-point data.

What the timings include

Both algorithms use the same points in each trial. Divide and Conquer includes initial sorting. Plotting, file output, validation and trace recording are excluded. Benchmark trials alternate execution order and use different seeded random datasets.

Why O(N log N)?

Two initial sorts cost O(N log N). Each recursive level partitions an already y-sorted list and scans its strip in O(N). Each strip point checks at most seven following points. Balanced recursion has O(log N) levels. Brute Force examines N(N−1)/2 pairs.

How the strip works

At each merge, d is the smaller of the two half-distances. Only points within distance d of the dividing line could form a better cross-half pair. The shaded region has width 2d in coordinate units, clipped to the plot. Its original width stays fixed while the best answer improves. When d=0, the strip collapses and no improvement is possible.

Scope of verification

Every generated dataset is checked before reporting. Randomized and exhaustive small-grid tests provide evidence, not a proof for every possible input. Distances are compared before rounding, using relative and absolute tolerances of 10⁻¹². Coordinates are finite, generated in a bounded range. The returned pair is also validated.
